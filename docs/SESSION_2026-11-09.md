# Catatan Sesi — 9 November 2026

**Topik:** Lima mini-game prioritas dan persiapan verifikasi Supabase
**Status akhir sesi:** Implementasi selesai di kode; verifikasi Supabase nyata belum dijalankan.

Dokumen ini merangkum percakapan, keputusan, pekerjaan, bukti eksekusi, dan langkah
lanjutan. Ini bukan transkrip mentah seluruh tool call, tetapi catatan yang cukup untuk
melanjutkan sesi berikutnya tanpa mengulang pekerjaan.

---

## 1. Permintaan pengguna

> "Bangun lima mini-game prioritas: Word Bank, Sentence Builder, Matching Pairs, Fill in
> the Blank, dan Picture Identification"

Konteks proyek: game edukasi 2D **Lentera** berbasis Vite + TypeScript + Phaser 4 +
Supabase. Lima mini-game harus punya mekanisme, tampilan, input, penilaian, dan feedback
sendiri — bukan variasi pilihan ganda. Kunci jawaban dan relasi pasangan tidak boleh
dikirim ke browser; penilaian harus di server. Konten harus soal nyata di database, bukan
data dummy frontend. Bahasa Sambas tidak boleh dibuat otomatis.

Setelah implementasi, pengguna bertanya apa yang perlu dikerjakan berikutnya, lalu meminta
melanjutkan. Karena kredensial Supabase belum tersedia, pekerjaan diarahkan ke persiapan
verifikasi dan pengamanan proyek.

### 3.2 Server dan database

- Migration baru: `supabase/migrations/20261108107000_question_pairs.sql`.
- Tabel `question_pairs` menyimpan `left_id`/`right_id` terpisah, unique per sisi, RLS
  aktif, dan **tanpa grant** ke `anon`/`authenticated`.
- `grade_question` menilai matching dengan memeriksa jumlah pasangan, distinct sisi, dan
  kecocokan setiap pasangan.
- Payload `start_lesson` mengirim `leftItems` dan `rightItems` terpisah. Kolom kanan
  diurutkan dengan `md5(right_id)` agar urutan tidak membocorkan pasangan.
- Feedback jawaban salah untuk matching mengembalikan daftar pasangan yang benar.

## 6. Langkah berikutnya

### P0 — Verifikasi nyata

1. Buat project Supabase.
2. Jalankan:
   ```bash
   cp .env.example .env
   ```
3. Isi:
   ```env
   VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=...
   ```
4. Jalankan enam migration berurutan:
   1. `20261108090000_identity.sql`
   2. `20261108100000_curriculum.sql`
   3. `20261108105000_curriculum_overview.sql`
   4. `20261108107000_question_pairs.sql`
   5. `20261108110000_curriculum_seed.sql`
   6. `20261108120000_lesson_engine.sql`
5. Buat akun uji dan jadikan developer:
   ```sql
   select public.bootstrap_developer('email-uji@contoh.com');
   ```
6. Tambahkan akun uji ke `.env`:
   ```env
   E2E_EMAIL=email-uji@contoh.com
   E2E_PASSWORD=password-akun-uji
   ```
7. Jalankan:
   ```bash
   npm run verify:supabase
   ```
8. Setelah API lulus, uji klik kelima mini-game di browser.
